# トークテーマくじ引き

交流会向けのトークテーマくじ引きアプリです。GitHub と Netlify をつなぐだけで公開できます。
2種類のくじが入っています。

| ページ | URL | 内容 |
| --- | --- | --- |
| トークテーマくじ引き | `/`（`index.html`） | **自分でテーマを登録**して引くくじ。全端末で内容と履歴が同期されます |
| 話題のくじ | `/wadai.html` | **500問を内蔵**した、登録不要ですぐ引けるくじ。10カテゴリから絞り込めます |

どちらのページからも、もう一方へのリンクが画面内にあります。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（ビルド不要） |
| `wadai.html` | 話題のくじ（500問内蔵・単独で動作） |
| `netlify/functions/kuji.mjs` | 同期API。`/api/kuji` で公開されます |
| `netlify.toml` | 公開設定（publish・functions・キャッシュ） |
| `package.json` | 同期APIが使う `@netlify/blobs` |

データは Netlify Blobs に保存されます。別途データベースの契約は不要です。

## 公開手順（GitHub 連携・所要5分ほど）

1. [Netlify](https://app.netlify.com/) にログイン（GitHub アカウントでログインすると連携が楽です）。
2. **Add new site → Import an existing project → GitHub** を選び、リポジトリ `yuudai0317/wadai-kuji` を選択。
   - 初回は *Configure the Netlify app on GitHub* が表示されるので、このリポジトリへのアクセスを許可します。
3. ブランチと設定を確認します。`netlify.toml` があるので、基本はそのままで大丈夫です。
   - Branch to deploy: 公開したいブランチ（`master`、または動作確認用なら作業ブランチ）
   - Build command: 空欄
   - Publish directory: `.`
4. **Deploy site** を押すと、1分ほどで `https://<サイト名>.netlify.app` が発行されます。これが公開リンクです。
5. サイト名は **Site configuration → Change site name** で好きな名前に変更できます（例: `merit-wadai-kuji.netlify.app`）。

以降は、このブランチに push するたびに自動で再デプロイされます。

## 話題のくじ（`/wadai.html`）

登録もログインも不要で、開いてボタンを押すだけのくじです。

- **500問を内蔵**しています。10カテゴリ × 50問で、重複はありません。
  - 自己紹介・その人らしさ／食べ物・お店／旅行・おでかけ／子ども時代・思い出／仕事・働き方／
    趣味・エンタメ／もしも・空想／価値観・ちょっと深い話／笑える失敗談・あるある／季節・日常のこと
- 上部のボタンでカテゴリを絞り込めます（「すべて」なら500問から）。
- 一度出た話題は同じ端末では二度出ません。残り数はボタンの下に表示されます。
- 直近10件が「これまでの話題」に残ります。
- 同期はありません（各端末で独立して動きます）。全員で内容を共有したい場合はトップページを使ってください。

問いかけを増やしたり書き換えたりする場合は、`wadai.html` の `THEME_DATA` を編集してください。
カテゴリごとの件数が50でなくても動きますが、残り数の分母表示は50/500の固定値です。

## 同期の使い方（操作は不要です）

公開URLを開いた人は、**全員が最初から自動で同期されます。** スイッチを押す必要はありません。

- 誰かがテーマを登録・編集・削除すると、リンクを開いている全員の画面に約4秒で反映されます。
- 誰かがくじを引くと、その結果が履歴に加わり、全員の「残り」から除外されます。
  同じテーマが別の人に重複して出ることがありません。
- 画面を切り替えて戻ってきたときは、待たずに最新を取りに行きます。
- 同期できているかは、見出しの右の「同期中」バッジで分かります。
  通信が切れると「接続待ち」になり、回復すると自動で同期を再開します。
- 後からリンクを開いた人も、その時点の最新のテーマ・履歴から始まります。
- 自分の画面に出ている当選札は、他の人の操作では消えません。

くじは1サイトにつき1つです。全員が同じ内容を編集できるため、
「すべて削除」「履歴と除外をリセット」も全員に反映されます。進行役だけが操作する運用がおすすめです。

### 同期スイッチ（テーマ編集の中）

「テーマを編集 → 抽選の設定」に **くじをみんなと同期する** スイッチがあります。
公開URLでは**最初からオン**なので、普段は触る必要はありません。

- オンのまま端末を持ち替えれば（タブレット↔スマホなど）、続きからそのまま使えます。
- オフにすると、その端末だけ切り離されます。オフの間の変更は他の端末に届かず、
  他の端末の変更もその端末には届きません（下書きはその端末に保存され、再読み込みしても残ります）。
- オンに戻したとき、内容が食い違っていれば「共有中に合わせる／この端末の内容を全員に反映する」を選べます。
- 見出し右のバッジで、**同期中 / 同期オフ / 接続待ち** が常に分かります。

なお、`index.html` をローカルでファイルとして直接開いた場合は API が無いため、
このスイッチはブラウザ内保存の切り替えとして働きます（既定はオフ）。

## 同期API

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/kuji` | 保存済みのくじを返します（未保存なら `null`） |
| POST | `/api/kuji` | `{themes, drawn, exclude, updatedAt}` を保存します |

くじは1サイトにつき1つ保存されます（URLを共有した全員が同じくじを見ます）。

## ローカルで動かす

```bash
npm install
npx netlify dev     # http://localhost:8888 で /api/kuji ごと動作します
```

`index.html` を直接ブラウザで開いても動きますが、その場合の同期はブラウザ内保存になります。
